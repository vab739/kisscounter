# Kiss Counter 💋

A simple responsive website with a light pink background.

The kiss count:
- Starts at 0 on September 11, 2026
- Increases by 2 every full 24 hours
- Works on mobile and desktop

## Files

- `index.html` — website structure
- `style.css` — design
- `script.js` — kiss counter logic

## Deploy with GitHub Pages

1. Create a GitHub account at https://github.com if needed.
2. Create a new repository called `kiss-counter`.
3. Upload these three website files:
   - `index.html`
   - `style.css`
   - `script.js`
4. Go to **Settings → Pages**.
5. Under **Build and deployment**, select:
   - Source: **Deploy from a branch**
   - Branch: **main**
   - Folder: **/(root)**
6. Save.

Your website will be available at:

https://YOUR-GITHUB-USERNAME.github.io/kiss-counter/

Replace `YOUR-GITHUB-USERNAME` with your GitHub username.
